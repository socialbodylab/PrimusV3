# DeviceManager v0.93

macOS release built from the V4 unified sender (`--product devices`).

## Changes

- **Monitor filtering** — replaced the search box, group dropdown, and manual IP add field with alphabetical character-name chips for quick filtering.
- **Card layout** — device cards are 25% narrower so more fit on screen at once.
- **Hello placement** — Hello moved to the firmware row at the bottom of each card.

## Validation

- `DeviceManager.app` Developer ID signed with network entitlements, notarized, and stapled
- `DeviceManager-0.93-macOS-arm64.dmg` signed, notarized, stapled, and verified with `hdiutil verify`
