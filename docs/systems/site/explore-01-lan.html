Encoding A · adjacency matrix

Source × target cells

Each cell lists every conversation. Plane letter + port + payload. Empty = no standing path. Dense: read columns for “what hits a Primus body,” rows for “what one app is allowed to do.”

Legend: S show · U setup · W watch · dashed outline = optional / secondary path

Encoding B · small multiples

One panel per plane

Same edges, split by job. Compare vertically: Show is fat traffic; Setup is many thin management edges; Watch is receivers → DeviceManager only.

Encoding C · nested scales

Four zoom levels, same system

Cast → apps → ports → opcodes. Each column is a finer grain of the column to its left. Pick a row to see how one show concern decomposes.

Encoding D · channel × phase

When each wire is busy

Rows are protocol channels. Columns are production phases. Marks show which app owns the channel in that phase. Makes “don’t FTP at GO” and “ArtDmx lives at GO” visible as time, not topology.
